# TG Media — Social Media Marketing Agency Website

A modern, high-performance website for **TG Media**, built with Next.js 16 (App Router), React 19, TypeScript, and Framer Motion.

## 🚀 Features

- **Dynamic Hero Section**: Staggered animated typography, floating responsive media grid with mixed video and imagery.
- **Interactive Services**: 3D geometric card representations, content creation spotlights, and strategic marketing breakdown.
- **Built on Results Section**: Custom orbital ring animation featuring live metric counters and dynamic icon movement.
- **Full Inquiry Contact Page (`/contact`)**:
  - Interactive multi-select service chips
  - Budget selector pills
  - Fast-track 15-minute discovery call booking card
  - Responsive validation with animated submission confirmation state
- **Floating Glass Navbar**: Scroll-spy indicator, blur backdrop, mobile drawer navigation, and active page detection.
- **Curtain Reveal Orange Footer**: Sticky bottom curtain reveal with newsletter sign-up, brand wordmark, and social links.
- **Smooth Inertia Scrolling**: Powered by Lenis for fluid desktop browsing.

## 🛠 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **UI Library**: [React 19](https://react.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS Variables & Scoped CSS Modules
- **Typography**: Magra & Libre Franklin (Google Fonts)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

### 3. Production Build
```bash
npm run build
npm run start
```
